=====================================================================
 SAFETY FILE — full model re-download + verification, ALL COMMANDS
 Use this if the pod/volume is ever lost and you must rebuild from a
 FRESH pod. Self-contained: works even if the repo scripts are gone.
 Source of truth otherwise: adgen-backend/scripts/pod-full-redownload.sh
                            adgen-backend/scripts/pod-check-models.sh
=====================================================================

WHEN TO USE THIS
-----------------
- "A40 out of capacity" and you had to spin up a brand-new pod
- Old pod's volume is unreachable / corrupted
- pod-check-models.sh reports MISSING or TRUNCATED files and a
  simple -c resume didn't fix it

DO NOT use this if the OLD pod is just stopped/restarted — the volume
still has everything, nothing to re-download. Only use for a pod that
starts from a truly empty /workspace/ComfyUI/models.


STEP 0 — confirm you actually need this
-----------------------------------------
SSH/web-terminal into the pod, then:

  ls /workspace/ComfyUI/models

If this already lists diffusion_models/ text_encoders/ vae/ loras/
etc. with real file sizes, STOP — run the CHECK section below first
instead of blindly re-downloading (redownloading is slow, ~205GB).


STEP 1 — install aria2c (resumable, faster than wget)
--------------------------------------------------------
  which aria2c >/dev/null 2>&1 || (apt-get update -qq && apt-get install -y aria2)

------------------------------------------------

           facerestore_models checkpoints latent_upscale_models \

 STEP 8 — CHECK EVERYTHING LANDED (run this after ANY of the above,

 render). Paste this whole block into the pod terminal.

cd /workspace/ComfyUI/models 2>/dev/null || { echo "wrong dir — cd to the volume-backed models/ first"; exit 1; }

check() {
  local path="$1" minmb="$2"
  if [ ! -f "$path" ]; then
    echo "MISSING  $path"
    return
  fi
  local sz=$(du -m "$path" | cut -f1)
  if [ "$sz" -lt "$minmb" ]; then
    echo "TRUNCATED  $path  (${sz}MB, expected >=${minmb}MB — re-download with -c)"
  else
    echo "OK  $path  (${sz}MB)"
  fi
}

=====================================================================
 STEP 9 — AFTER a full re-download: repoint the backend
=====================================================================
1. Get the NEW pod's port-8188 proxy URL from the RunPod dashboard
   (e.g. https://xxxxxxxxxx-8188.proxy.runpod.net)
2. Edit adgen-backend/.env:
     COMFY_POD_URLS=<new proxy URL>
3. Restart the backend:
     cd adgen-backend
     ./.venv/bin/uvicorn app.main:app --port 8000
   (only after /queue shows idle if it was already running)
4. Do one full pipeline smoke test before telling the client anything
   is fixed: portrait generate -> approve -> variant -> a short render
   -> QC gate check -> export.


NOTES / GOTCHAS
-----------------
- Total size TIER1+TIER2 ≈ 120 GB. Full --all ≈ 205 GB. Check pod
  disk budget before starting (410GB volume = comfortable headroom).
- HF signed URLs decay after a while — if a transfer dies partway,
  just re-run the same aria2c line, -c resumes instead of restarting.
- Never swap qwen_image_edit_2509_fp8mixed.safetensors for the
  e4m3fn or plain fp8 variant — confirmed black-frame cause on this
  A40 (Ampere). fp8mixed is the only proven-safe flavor here.
- Do NOT use --use-sage-attention in the ComfyUI launch flags on this
  pod — confirmed kernel bug source in a prior incident.
- This is a STOPGAP procedure. The durable fix (no re-download ever
  again) is migrating to a RunPod Network Volume — ask to resume that
  work if you want it done properly instead of repeating this drill.
